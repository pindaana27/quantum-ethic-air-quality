Build history.js

This page downloads modeled hourly PM2.5 for every grid square and every community on the map, averages it into daily values, and saves the result as history.js. Open it once, click Build, wait a minute or two, then upload the downloaded file into the same folder as index.html. Re-run it whenever you want the history extended to today.

With the token filled in, the result is written straight to history.js on the site. With it blank, the file downloads and you upload it yourself.
